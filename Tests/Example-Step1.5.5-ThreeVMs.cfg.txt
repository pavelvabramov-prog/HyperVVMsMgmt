#-----VM's PARAMETERS DESCRIPTION---------------------------------------------------------------------------------------------

#FolderNameOverride:        Overrides VM folder name under Destination. Allowed only for a SINGLE VM per VM Parameters section.

#0 Destination:             Base destination folder. Ignored if [1] is specified.
#1 C, InPlace:              Uses an existing VHDX directly. Overrides all other disk options except [5].
#2 C, Source:               Copies an existing VHDX. Ignored if [1] is specified.
#3 C, Move Src (Move):      Moves the source VHDX instead of copying it. Requires [2].
#4 C, Size:                 Size of a new VHDX.
#5 C, New Size Incr.to:     Expands an existing or copied VHDX to the specified size. Ignored for new disks [4].
#6 C, If Fixed (Y):         Creates a fixed-size VHDX when using [4].
#7 C, V.Disks Folder:       VHDX subfolder within the VM folder. Ignored if [1] is specified.
#8 C, Dest.Override:        Overrides the default VHDX destination path and [7]. Ignored if [1] is specified.
